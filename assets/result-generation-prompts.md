# DBTI Result Image Generation Notes

Use this file as the source of truth when regenerating breed-specific result images.

The accepted visual direction from the original Codex thread is:

- square 1:1 result illustration
- classic MBTI low-poly flat geometric character illustration
- angular polygon facets, crisp vector-like raster
- muted pastel background, polished UI asset quality
- each result is an independent single-scene illustration
- preserve the scene, props, composition, humor, and personality read
- when making breed variants, redraw the dog as the target breed inside the same scene
- do not paste a dog sticker on top of the original image
- no watermark, no logos, no readable text unless the result prompt explicitly allows it

Shared style line:

```text
Style: flat low-poly geometric character design inspired by classic MBTI 16-personality avatar posters, playful Chinese internet meme tone, pastel background, crisp shapes, polished UI asset quality.
```
